# Словолупа — расширение для Chrome

Частотная карта абзаца по щелчку или выделенного текста. Русский и английский, смешанные тексты, объединение словоформ по основе Snowball. Частотный анализ и перевод выполняются на устройстве. По отдельной кнопке выделение можно отправить в DarkAPI для объяснения.

## Установка — без сборки

В проект уже включена готовая папка `extension`.

1. Откройте `chrome://extensions` в Chrome.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `C:\prj\pft4\extension` (именно папку с `manifest.json`).
5. Обновите уже открытые веб-страницы. При необходимости закрепите значок Словолупы на панели Chrome.

Для установки из архива сначала распакуйте архив и выберите полученную папку с `manifest.json`.

## Как пользоваться

- **Щелчок по абзацу.** Щёлкните левой кнопкой мыши по тексту.
- **Выделение мышью.** Выделяйте один или несколько абзацев. Окно появляется после отпускания кнопки мыши.
- **Перевод.** Для английского текста над картой появляется русский перевод. Встроенный переводчик Chrome работает на устройстве и при первом использовании может загрузить языковую модель. Имена распознаются по написанию, поэтому необычные имена и неоднозначные заглавные слова могут обрабатываться неточно.
- **Выделение клавиатурой.** Используйте Shift + стрелки или Ctrl + A на странице. Анализ появляется после небольшой паузы в изменении выделения.
- **Окно выделения** остаётся при уводе курсора, прокрутке, изменении размеров окна и снятии выделения программой страницы. Оно закрывается по щелчку вне окна, нажатию клавиши вне окна, Escape или кнопке ×. После закрытия то же выделение само по себе окно повторно не открывает.
- **Кнопки внутри окна** переключают карту, частоты и показатели. Они не снимают исходное выделение. Клавиатура внутри окна позволяет работать с вкладками; Escape закрывает его. Текст карты можно выделять и копировать.
- В карте чаще встречающиеся значимые слова крупнее и жирнее. Местоимения, междометия, прочие стоп-слова и короткие слова приглушены. Кнопка «Подсветить воду» показывает их тёплым фоном. При наведении на слово видны основа, категория и число повторений.
- Окно располагается в правой половине видимой области вкладки с отступом 10 px со всех сторон. В очень маленькой области отступ уменьшается. Длинный текст прокручивается внутри окна. Во вложенном фрейме окно ограничивается областью этого фрейма.

По значку расширения можно отключить анализ целиком или включить подсветку воды. Настройки сохраняются на этом устройстве и сразу применяются к открытым страницам.

### Объяснить как ребенку

При открытии карты текста выделение или щёлкнутый абзац автоматически подставляется в промпт и запускает объяснение для восьмиклассников в отдельном окне. Кнопка слева от «Подсветить воду» позволяет открыть объяснение повторно. Это работает и при чтении PDF и DjVu.

1. Установите расширение. В меню Словолупы раскройте «Как включить „Объяснить как ребенку“» и скопируйте идентификатор.
2. В кабинете DarkAPI активируйте промокод, затем в «Быстром старте» выберите **Обычный API** и скопируйте Base URL. На вкладке «Модели» выберите модель и скопируйте её точный ID.
3. В папке установленного расширения откройте PowerShell и запустите `.\Start-Explanation.ps1`. Нужен Node.js 20.3 или новее. Введите идентификатор расширения, ключ DarkAPI, Base URL и ID модели. Оставьте окно помощника открытым.
4. Выделите текст или щёлкните по абзацу. Помощник сразу отправит промпт в DarkAPI. Ключ остаётся у помощника на компьютере. Запросы учитываются в DarkAPI.

Если параметры уже заданы в переменных окружения `DARKAPI_API_KEY`, `DARKAPI_BASE_URL` и `DARKAPI_MODEL`, помощника можно запустить командой `node explain-server.mjs <идентификатор-расширения>` из той же папки. Для изменения лимита ответа задайте `DARKAPI_MAX_TOKENS` (по умолчанию 1200, максимум 2500); для ожидания ответа — `DARKAPI_TIMEOUT_MS` (по умолчанию 75000, от 15000 до 120000).

Чтобы не вводить параметры при каждом запуске, скопируйте `Start-Explanation.local.example.ps1` в `Start-Explanation.local.ps1` в папке `extension`, один раз заполните ключи и запускайте локальную копию. Она исключена из Git через `.gitignore`; не вставляйте ключи в исходные файлы, README или сообщения чата.

### Качественное произношение

Кнопка «Произнести вслух» использует нейросетевой Yandex SpeechKit вместо системного голоса Chrome. При запуске `Start-Explanation.ps1` введите API-ключ SpeechKit (ввод скрыт); он остаётся только в памяти локального помощника. Для ключа нужна роль `ai.speechkit-tts.user`. Если оставить поле пустым, объяснения продолжат работать, а озвучка подскажет, как её включить. В SpeechKit передаётся только текст объяснения для синтеза речи; запросы могут тарифицироваться по условиям Yandex Cloud. По умолчанию выбран голос `marina` с дружелюбной интонацией. Чтобы сменить его, перед запуском помощника задайте переменную `YANDEX_SPEECHKIT_VOICE` (например, `filipp` или `jane`).

## Анализ и связь с Istio

За основу взято опубликованное [описание анализа Istio](https://istio.com/ru/text/analyz) и [руководство по формулам](https://istio.com/guides/text-analysis-metrics). Это независимая реализация, а не подключение к сервису Istio. Совпадение всех чисел с сайтом не гарантируется: используются собственные локальные стоп-списки и Snowball вместо закрытой модели сервиса.

- Слова выделяются по буквам Unicode; внутренние апострофы и дефисы сохраняются. Числа и пунктуация остаются в тексте, но не считаются словами. Пробелы, переносы, символы и порядок слов сохраняются из извлечённой строки. Для абзаца используется видимый `innerText`, для выделения — `Selection.toString()`.
- Регистр, варианты апострофа и `ё/е` нормализуются только для сравнения. В карте остаётся исходное написание.
- Русские словоформы обрабатывает Snowball Russian, английские — Snowball English (Porter2) из `snowball-stemmers 0.6.0`. Например, «текст / тексты / текстом» и «write / writes / writing» объединяются. Это **стемминг**, приближение к основе, а не полный морфологический разбор: чередования корня, нерегулярные формы, омонимы и смысловая неоднозначность могут давать неточные группы. Неподдерживаемые алфавиты сохраняются и группируются по нормализованному написанию.
- Вода — совпадения со стоп-списками, включая местоимения и междометия, а также слова короче трёх букв. Эти категории взаимоисключающие. Слова проверяются по нормализованной полной форме, чтобы случайное совпадение основ не превращало значимое слово в стоп-слово.
- Ядро — слова, оставшиеся после фильтра воды. **Водность** = `floor(водные слова / все слова × 100)`. Для пустого текста — 0%, для текста только из воды — 100%. Последнее отличается от описанного Istio особого случая, когда при пустом ядре интерфейс может показывать 0%.
- **Классическая тошнота** = `√ максимальной частоты основы`, включая стоп-слова, с усечением до двух знаков; для пустого текста — 0.
- Словарь — число уникальных основ. В частотах показан топ-10 основ ядра, число повторений, доля в тексте и доля в ядре. Проценты усечены до одного знака.
- Размер и насыщенность растут по числу повторений основы в абзаце или выделении. Одиночные слова отображаются размером 16 px и насыщенностью 400. Частые слова плавно приближаются к 60 px и насыщенности 800. Вода отображается размером 14 px и насыщенностью 400. Вариативный шрифт Manrope загружается из расширения.

Стоп-списки находятся в `src/stopwords.cjs`. Их можно расширять; после изменения исходников нужна сборка и обновление расширения.

## Ограничения Chrome

### PDF и DjVu

Нажмите значок Словолупы → **Открыть PDF или DjVu** и выберите локальный файл. Для каждой страницы отображаются оригинал с иллюстрациями, таблицами и диаграммами и текст для анализа. На узком экране текст расположен под оригиналом. Щёлкните по абзацу в текстовой части или выделите нужный фрагмент мышью. Файл обрабатывается на устройстве.

Кнопка **«Сохранить закладку»** создаёт небольшой файл `имя-документа.json` с номером страницы и позицией чтения. В диалоге сохранения выберите папку, где находится PDF или DjVu. Для продолжения чтения снова откройте исходный файл, нажмите **«Открыть закладку»** и выберите этот JSON. Закладка проверяет имя, размер и дату изменения документа, поэтому не применяется к другому файлу.

В текстовой части порядок чтения сложных таблиц и колонок может отличаться от оригинала. Сканы отображаются, а для анализа их текста потребуется предварительное OCR. Для многофайлового DjVu требуется копия, объединённая в один файл. Поддерживаются PDF без пароля.

Словолупа использует [DjVu.js](https://github.com/RussCoder/djvujs) для декодирования DjVu. Исходники декодера и условия GNU GPL v2 находятся в папке `extension/djvu-source`.

Расширение работает на обычных HTTP/HTTPS-страницах и, при разрешении пользователя, локальных HTML-файлах. На служебных страницах Chrome, в Chrome Web Store и во встроенном просмотрщике PDF внедрение запрещено браузером. Для локальных файлов включите «Разрешить доступ к URL файлов» в карточке расширения. Поля ввода и редактируемые области намеренно не анализируются автоматически. Закрытые Shadow DOM страниц могут быть недоступны.

Разрешение `storage` используется для настроек. Автоматический доступ к тексту сайтов нужен для щелчков и выделений. Доступ к `127.0.0.1` нужен для связи с помощником объяснений на вашем компьютере.

## Разработка и демонстрация

Нужен Node.js 20 или новее.

```powershell
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

Браузерные проверки загружают **настоящее расширение** в отдельный временный профиль Chromium, проверяют щелчок и выделение мышью, границы окна, настройки и безопасное отображение текста. Пользовательский профиль Chrome не используется. Снимки результата появляются в `test-results`.

```powershell
npm run demo
```

Откройте `http://127.0.0.1:4173`: демонстрация работает и без установки расширения. Страница `http://127.0.0.1:4173/?native=1` не подключает демонстрационный скрипт и предназначена для проверки установленного расширения.

Файлы расширения:

- `extension/` — готовая версия для установки;
- `src/content.js` — события мыши, выделения, клавиатуры;
- `src/lens.js` — окно с изолированными стилями в Shadow DOM;
- `src/analyzer.cjs`, `src/stopwords.cjs` — анализ и словари;
- `src/popup.*` — настройки;
- `tests/` — проверки анализатора и расширения в браузере;
- `THIRD_PARTY_NOTICES.txt` — лицензия стороннего стеммера.

После новой сборки нажмите кнопку обновления в карточке расширения и перезагрузите тестируемые веб-страницы.
